# OPT 2026 workshop submission

This directory contains a separate, anonymous manuscript for the 18th
Workshop on Optimization for Machine Learning at NeurIPS 2026. It does not
replace `../paper.tex`.

The official OPT 2026 class and its JMLR dependencies were downloaded from
<https://opt-ml.org/opt2026_style.zip> on August 9, 2026.

Build with:

```bash
make
```

Submission constraints verified against the official call:

- deadline: September 4, 2026 AoE;
- anonymous, double-blind review;
- soft limit of five main-text pages, excluding references and appendices;
- official OPT 2026 style required;
- concurrent submission to another NeurIPS workshop is prohibited.

See `SUBMISSION_CHECKLIST.md` before uploading. The present PDF is a truthful
workshop draft, not yet a recommendation to submit unchanged.
